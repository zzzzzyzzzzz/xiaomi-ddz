# 小咪打牌中

第一人称 3D 斗地主网页游戏。你坐在牌桌前，和两只低多边形小黑猫（煤球、小咪）打牌。

## 玩法

- 标准三人斗地主：叫分（1–3 分）抢地主，地主拿三张底牌。
- 支持全部牌型：单张、对子、三带一/二、顺子、连对、飞机（带翅膀）、四带二、炸弹、王炸。
- 炸弹、王炸、春天各 ×2。积分保存在浏览器本地。
- 点牌或在牌上滑动选牌，「提示」会从小到大轮流推荐能出的牌。

## 小猫

- `lowpoly_cat.glb`：在 Blender 4.5 里建模和绑定，22 根骨骼。
- 动画：`Sway`（待机晃头、偶尔眨眼）、`ShakeHead_Closed`（闭眼摇头，眼睛是白色一条线）、`Nod_Happy`（^ ^ 点头）。
- 表情切换做在骨骼上（四组眼睛贴片各挂一根骨骼），所以在 three.js 里直接用 `AnimationMixer` 播放就会自动换表情。

## 技术

- 纯静态页面：`index.html` + `lowpoly_cat.glb`，无需构建。
- three.js r160（jsDelivr CDN），像素化渲染。
- 本地运行：在仓库目录里起一个静态服务器，例如 `python -m http.server`，然后打开 http://localhost:8000 。直接双击 index.html 打不开模型（浏览器禁止 file:// 读取）。
