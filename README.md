# 小咪打牌中

第一人称 3D 斗地主网页游戏。你坐在野餐垫或牌桌前，用两只猫爪拿着牌，和小猫们打牌。可以一个人和 AI 小猫打，也可以开房间和朋友联机。

## 玩法

- 标准三人斗地主：叫分（1–3 分）抢地主，地主拿三张底牌。
- 支持全部牌型：单张、对子、三带一/二、顺子、连对、飞机（带翅膀）、四带二、炸弹、王炸。
- 炸弹、王炸、春天各 ×2。单人模式的积分保存在浏览器本地。
- 点牌或在牌上滑动选牌，「提示」会从小到大轮流推荐能出的牌。

## 和朋友联机

1. 打开网站，填昵称、选一只小猫，点「创建房间」。
2. 点「复制邀请链接」发给朋友（最多 3 个真人）。朋友打开链接，填昵称后点「加入」。
3. 人到齐后房主点「开始」。没人坐的位置由 AI 小猫代打。

联机是浏览器之间直连（PeerJS 的免费公共信令服务），不用注册账号。房主的浏览器负责发牌和判定，房主关掉页面牌局就会结束。

## 互动

点对面小猫头顶的名字，可以送花、丢小鱼干、比心、扔毛线球或者扔番茄。联机时所有人都能看到。

## 小猫

- 6 种形象可选：煤球黑、橘子、奶牛、蓝灰、三花、梦粉。你选的形象也会体现在自己的猫爪上。
- `lowpoly_cat.glb`：在 Blender 4.5 里建模和绑定，22 根骨骼，动画有 `Sway`、`ShakeHead_Closed`、`Nod_Happy`，表情切换做在骨骼上。

## 技术

- 纯静态页面：`index.html` + `lowpoly_cat.glb`，无需构建。
- three.js r160、PeerJS 1.5.4（jsDelivr CDN）。音乐和音效都是 Web Audio 实时合成。
- 本地运行：在仓库目录里起一个静态服务器，例如 `python -m http.server`，然后打开 http://localhost:8000 。
